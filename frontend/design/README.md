# Tempica デザイン（正：source of truth）

このディレクトリには Claude Design（claude.ai/design）で作成した UI 素案を格納しています。

- **`Tempica.dc.html`** … Claude Design 出力の自己完結 HTML モックアップ。デスクトップ／モバイル両フレームで
  主要画面（ログイン・初期セットアップ・ダッシュボード・打刻・自分の勤怠・申請作成/一覧・承認・シフト・
  休暇・勤務形態・RBAC・締め/CSV）を網羅。

> ⚠️ **このデザインが「正」です。** 作成途中でデザイン方針が変更されたため、`docs/design.md`（設計書）の
> デザインに関する記載（メインカラー = ブルー #2563EB 等）よりも、**本ファイルの実物を優先**します。
> フロント実装時は `docs/design.md` の配色記述ではなく、このモックアップを参照してください。

## 実装メモ

- 実装は `frontend/`（Next.js + Tailwind）で行う。上記トークンを `tailwind.config.ts` と
  `app/globals.css` の CSS 変数に反映する。
- `Tempica.dc.html` は `./support.js`（Claude Design ランタイム）を参照しているが、リポジトリには同梱しない
  （ブラウザ単体ではプレビュー不可。設計の参照用として保管）。
- バックエンド連携：`/api/v1`、認証は HttpOnly セッション Cookie のため `fetch(..., { credentials: 'include' })`。
