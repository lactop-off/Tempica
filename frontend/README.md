# Tempica フロントエンド（実装待ち）

このディレクトリには **React + TypeScript + Next.js**（Tailwind CSS + shadcn/ui）による
フロントエンドが入る予定です。

## ステータス

フロントエンドの本実装は、**Claude Design によるデザイン素案（`docs/design-prompt.md` に基づく）が
確定してから**着手します。それまではバックエンド（`../backend`）と基盤の実装を先行しています。

現時点ではビルド可能な最小プレースホルダ（「準備中」ページ）のみを置いています。

## バックエンド連携

- API ベース URL: `http://backend:3000/api/v1`（compose では環境変数 `API_BASE_URL`）
- 認証は **HttpOnly セッション Cookie**。`fetch` は `credentials: 'include'` で呼び出すこと。
- API 仕様は バックエンド起動後の Swagger UI（`/api/docs`）を参照。
